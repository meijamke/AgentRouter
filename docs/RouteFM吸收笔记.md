# RouteFM 吸收笔记（跨域路由的"少样本迁移"路线）

> **来源**：RouteFM《Pretrain Once, Route Anywhere》(arXiv 2609.37362, E2)。
> **定位**：把"模型路由"做成**基础模型**——预训练一次，冻结参数，新场景靠"几条行为观测"在上下文里自适应，不重训、不微调、不绑模型身份。
> **本文目的**：记下可吸收的 3 条 + 不能照搬的 2 条，落到本方案 VAS/CE。

---

## 一、核心洞察：路由是可复用的"目标条件排序"

> 不管题目是数学还是多模态、模型池是 4 个还是 24 个，底层结构永远同一件事——**从行为推断能力 → 按目标排序**。

所以这个能力可**跨环境共享**，做成一个基础模型（foundation model）。当前所有"本地拟合"范式（RLCascadeRouter / RSI 家族 / 我们 VAS/CE）都是"在一个环境里拟合一个路由器"，换域/换模型就重新拟合——RouteFM 要跳出这个范式。

---

## 二、可吸收的 3 条

### 1. 「匿名候选 + 行为观测」的表示 → 升级 cap_embed

- RouteFM 不喂模型名/厂商/参数量，只喂**行为观测**：`B_m = { (题目向量, 该模型在这题的质量分, 归一化成本) }`；
- 把每个候选的变长观测序列压成 **L=24 个"潜在能力 token"** `C_m`（cross-attention 取信息 + self-attention 交换，**不被预定义技能类别监督**，端到端学出来）。

**落地**：我们的 `cap_embed` 从"静态能力档向量"升级成**"从行为观测动态构造的能力画像"**——这样同时吃下"换模型"和"换域"。这是往"少样本跨域"方向走的关键一步。

### 2. 「预训练一次」→ 可复用路由底座

- RouteFM 在**多环境下情节化预训练**（每个 episode 随机变任务/候选组成/顺序/上下文量 K∈{8…1024}），得到一个冻结的路由底座；
- 新环境只喂几条观测、冻结参数直接用（8 条观测超重训基线 +2.23）。

**落地**：用我们已有的多 benchmark 做一次**跨环境预训练**，得到可复用路由底座，再在设备池上 IL+RL 微调。直接回应当前"每换一个场景就重训"的痛点。

### 3. regret loss 显式化

- RouteFM 损失 = 三点回归 + 成对排序 + **路由 regret**（`L_regret` = 选出来的模型质量 vs 最优模型质量之差，权重课程式加大）；
- 和 RLCascadeRouter 的"增量奖励"是同一思想，但**显式、可调**。

**落地**：cost-aware RL 里显式加 regret 项，别只靠隐式的 shaping 增量。

### 4. λ 条件化（部署偏好旋钮，冻结路由器换 λ 免重训）

- RouteFM 决策 `m* = argmax_m (ŷ_m − λ·ĉ_m)`，**λ 是部署偏好旋钮**，同一个冻结路由器换 λ **不用重训**。

**落地**：把 λ（成本旋钮）**条件化进策略输入**，避免"一个 λ = 一个策略"的重训成本。（已写入架构方案 §2。）

---

## 三、不能照搬的 2 条（守弱边界）

1. **RouteFM 是"单步路由"，不是多步 MDP**：决策 = `argmax(ŷ − λĉ)`，每次只选一个模型，没有"停/续 + 每步选设备 + 累计成本 + KV 迁移"。**它只能搬"表示层 / 预训练底座"，不能直接替换 VAS/CE**。

2. **"8 条观测"是冷启动成本，且优势只在低上下文**：
   - 新模型上线前，得先攒 8 条**带标签**观测（质量分），这 8 条从哪来？端侧是真实冷启动难题；
   - RouteFM 优势**只集中在观测很少时**（K=8 +2.23），观测充足后 ≈ 基线（+0.07）——它不解决"观测够多还要更强"；
   - 成本 c̃ 是**每 episode 内归一化的相对值**，不算绝对成本/延迟/KV——只覆盖"质量 + 弱成本"。

---

## 四、四条边界提醒（守弱）

- **零样本跨域无人解决**（RouteFM 也要"8 条观测"起步）——别预设"领域无关特征就能零样本跨域"；
- **少样本跨域 = RouteFM 是当前最强**，但需"行为观测 + 冷启动攒几条"；
- 我们的"领域无关特征（cap_embed/P(fail)/成本/进度）"和 RouteFM 的"通用路由表征"是**同一目标的两条路线**（特征工程 vs 预训练），**可结合**：用 RouteFM 预训练表征当 VAS/CE 初始化；
- 落地优先级：**先把离线答案表 + 查表训练（RLCascadeRouter 那条）做出来**，RouteFM 的表示升级排 M2（需要攒行为观测，当前 M1 还没这个数据管道）。
