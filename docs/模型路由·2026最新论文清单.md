## 关键归纳（对本项目）

1. **上限有了定量定义**：共失败率 β（2606.27288）——跨设备路由里"手机 PC 同时都答错"的比例就是天然上限，训练前可先测；
2. **RL 直优已成熟**：RLCascadeRouter（2608.15817）证明"跳过质量估计器、直接 RL 优化路由"可行且更强、还能泛化到新模型——这是蒸馏 judge 的长期替代；
3. **KV 切换成本可被工程压低**：CacheBridge（2609.00891）+ Unified AI Gateway（2609.06940，路由与 KV 联合管理）给出跨模型 KV 传输/联合优化方案，保守策略有了消解手段；
4. **Agent 多步 RL 不再是空白**：Hera（2605.24598）做 step-level device-cloud RL，GraphPlanner（2604.23626）做 agentic MDP workflow——"直接把 agent 多步路由做 RL"已成熟；
5. **路由成为 agent 能力**：CERA-MoA（2609.18779，co-evolve）、GraphPlanner（agentic router）、Router-R1（router-as-LLM）验证了"路由内化为 agent 能力"的方向；
6. **agent 多步路由有专用评测与范式**：TwinRouterBench（2605.18859）、ProgRouter（2608.25992，进度引导）。

> 说明：本清单为**人工筛选**的"最相关"子集；arXiv 中 `LLM model routing` 泛指命中 2000+ 篇，未穷举，也未含 2026 年之前（如 RouteLLM/FrugalGPT 等基线）。
